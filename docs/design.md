# ARTMO Design Guide

- 분위기: 미술관 전시 도록처럼 차분하게. 작품이 주인공이고 UI는 뒤로 물러난다.
- 색: 배경 따뜻한 미색 `#F6F3EE`, 본문 진한 회갈색 `#2B2724`, 강조색 하나(깊은 남색 `#1F3A5F`). 작품 위에 색 필터를 씌우지 않는다.
- 어두운 전시실(결과 화면·공유 카드): 배경 `#121110`, 글자 `#EEE7DC`, 강조색 황동 `#F2B740`. 작품 뒤에만 은은한 조명(radial glow)을 두고, 작품은 흰 테두리·여백 없이 그림자로만 띄운다. 값은 `theme.room`.
- 글꼴: 제목·작품명 세리프(Noto Serif KR), 본문·버튼 산세리프(Pretendard).
- 카드(1080×1920, 위→아래, 미술관 설명판 구성): 작품(테두리 없이 그림자만) → 작품명·작가·연도 → 짧은 금색 선 → 사용자 문장(따옴표) → 해석 2–3문장 → 작은 ARTMO 로고·출처 미술관. 배경은 작품 색이 흐리게 번진 잔광.
- 레이아웃: 모바일 우선. 390px에서 먼저 확인하고 PC는 가운데 정렬, 최대 폭 720px.
- 홈: 입력란 하나에 집중. 자리표시 글로 예시 문장 제공(예: "수평선 한가운데 선 고독한 사람 같아").
- 색과 간격 값은 `src/styles/theme.ts`에만 정의하고 컴포넌트에서 직접 쓰지 않는다.
